# Sweet Crumbs Bakery — Touchstone 3

A four-page, fictional bakery website with mobile-first CSS, Flexbox, and a desktop media query.

## Pages
- `index.html` — home
- `about.html` — about
- `menu.html` — menu
- `contact.html` — contact demo form
- `styles.css` — shared external stylesheet

## Preview
Open `index.html` in a browser. Navigation works locally. The contact form is a demonstration and does not send messages.
